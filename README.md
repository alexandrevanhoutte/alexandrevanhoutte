## 🚀 Featured projects

### [Callio — Real-time AI Receptionist](https://github.com/alexandrevanhoutte/CallioPoc)

A **Go-based, backend-focused proof of concept** for real-time AI voice conversations using Gemini Live. The browser simulates a call; it does **not** connect to the phone network.

- Full-duplex audio streaming over WebSockets, with goroutines and context-based cancellation
- Provider-independent voice interfaces and explicit call lifecycle management
- Live transcription, interruptions, and simulated human handoff
- Structured post-call summaries and French, English, and Korean support

**Stack:** Go · Gemini Live · WebSockets · Vanilla JavaScript
